Brote tiene integración nativa con **Shopify Storefront API**. Tu agente IA consulta productos, variantes, precios, stock, y arma carritos pre-llenos que el cliente solo tiene que pagar. Disponible desde el plan **Starter**.

## Qué hace el agente con Shopify

- **Lookup de catálogo**: cuando el cliente pregunta "¿tienen el modelo X en color azul?", el agente busca en tu Shopify y responde con los detalles reales + foto + precio.
- **Verificación de stock**: el agente sabe si hay stock antes de prometer. Si no hay, ofrece alternativas o sugiere lista de espera.
- **Build cart link**: genera un link de carrito pre-armado con los productos que el cliente eligió. El cliente solo da click → checkout pre-poblado en tu Shopify.
- **Recomendación cruzada**: si el cliente compra X, el agente sugiere productos relacionados según tu data Shopify.

<Aside type="tip" title="Cart link > Configurador">
Cuando el cliente identificó variante + cantidad, el agente prioriza mandar un **cart link** directo (deeplink al checkout Shopify) sobre mandarlo al configurador. Menos clicks = más conversión.
</Aside>

## Cómo conectar

1. Entra a **Configuración → Integraciones → Shopify**.
2. Ingresa el **handle de tu tienda** (ej: `mitienda.myshopify.com` o `mitienda.com`).
3. Generamos automáticamente un Storefront API access token leyendo `mitienda.com/products.json` (público).
4. Si tu tienda tiene productos no listados públicamente (private storefront), pegas el token Storefront manual.

## Suscripciones nativas

Si tu Shopify usa una app de suscripciones (Bold, Recharge, Native Subscriptions), las suscripciones aparecen como **variantes** del producto. Brote las detecta automáticamente — el cliente puede pedir "lo quiero suscrito" y el agente arma el cart con la variante suscripción.

## Sincronización

La data se lee on-demand cuando el agente la necesita — **no hay sync periódico**. Esto significa:

- Tus precios siempre están actualizados (sin lag de cache).
- Tu stock es real-time.
- No tenemos copia del catálogo en Brote — confiamos en Shopify como source of truth.

## Combinable con Mercado Pago

Si quieres que el cobro pase por **Mercado Pago** en lugar del checkout nativo Shopify, lo configuras. El agente genera link de pago MP, el cliente paga, y el webhook MP dispara la orden en tu Shopify (vía Zapier o Webhooks).
