Brote es un **servidor MCP** (Model Context Protocol — protocolo abierto de
Anthropic). Cualquier cliente compatible — Claude Desktop, ChatGPT Custom
Connectors, agentes propios — puede conectarse y usar las tools de Brote
como si fueran nativas del modelo.

<Aside type="tip">
Esto es lo que llamamos **agente-to-agente**: tú hablas con Claude, Claude
habla con Brote, Brote actúa sobre tus conversaciones, tus contactos, tus
pagos y tu logística. Sin que tú hagas APIs ni Zapier.
</Aside>

## Qué puedes hacer

Hoy Brote expone **9 tools** al protocolo MCP:

| Tool | Qué hace |
|---|---|
| `list_conversations` | Lista conversaciones del inbox con filtros (status, channel) |
| `get_conversation` | Detalle + últimos N mensajes de una conversación |
| `send_message` | Manda mensaje al cliente (con auto-handoff de IA) |
| `upsert_contact` | Crea o actualiza contacto por phone/email |
| `assign_tag` | Agrega un tag a un contacto |
| `change_lifecycle_stage` | Cambia etapa (lead → mql → … → customer) |
| `build_payment_link` | Genera link Mercado Pago |
| `quote_shipping` | Cotiza envío Chilexpress o Starken |
| `get_inbox_metrics` | KPIs del inbox últimos N días |

Próximas tools en roadmap: `lookup_product` (catálogo Shopify),
`check_shipping_coverage`, `track_shipment`, `quote_shipping_starken`,
`add_internal_note`, `get_contact_history`.

## Endpoint y autenticación

- **URL**: `https://brote.ai/api/mcp`
- **Transport**: HTTP + JSON-RPC 2.0
- **Auth**: `Authorization: Bearer brote_live_TU_API_KEY`
- **Protocol version**: `2024-11-05`

Para generar una API key:
1. Ve a **Settings → Integraciones → "Conecta con 6.000+ apps"**.
2. Click **"Generar API key"**. Copiá el token (se muestra una sola vez).

## Conectar desde Claude Desktop

<Aside type="caution">
Claude Desktop al día de hoy **solo soporta MCP via stdio**, no HTTP directo.
Para conectarte a un servidor MCP HTTP como Brote, usamos `mcp-remote`
(paquete npm) como bridge stdio→HTTP. Necesitás Node + npx instalados
en tu máquina.
</Aside>

1. Abrí Claude Desktop → **Settings → Developer → Edit Config**, o editá
   manualmente `~/Library/Application Support/Claude/claude_desktop_config.json`
   en macOS (equivalente en Windows).
2. Agregá la entrada `"brote"` dentro de `mcpServers` — **sin borrar las
   otras** que ya tengas (filesystem, notebooklm, etc):

```json
{
  "mcpServers": {
    "brote": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://brote.ai/api/mcp",
        "--header",
        "Authorization: Bearer brote_live_TU_API_KEY_AQUI"
      ]
    }
  }
}
```

3. Reiniciá Claude Desktop completamente (cmd+Q + abrir de nuevo, no
   solo cerrar la ventana).
4. En cualquier conversación, Claude va a tener acceso a las 9 tools de
   Brote. Probá pedidos como:
   - *"Listame mis 10 conversaciones abiertas más recientes de Brote"*
   - *"Cambia el lifecycle de Pedro González a customer"*
   - *"Cotizá un envío de 2kg a Providencia"*
   - *"Generá un link de pago Mercado Pago por $25.000 con descripción 'Sesión de fotos'"*

### Cómo es el handshake (qué pasa por debajo)

```
┌────────────────┐                                ┌────────────────┐
│ Claude Desktop │                                │   brote.ai     │
│    (stdio)     │                                │   /api/mcp     │
└───────┬────────┘                                └────────┬───────┘
        │                                                  │
        │  1. spawn `npx mcp-remote https://brote.ai/...` │
        │ ───────────────────────────────────────────────►│
        │                                                  │
        │  2. POST initialize                             │
        │ ───────────────────────────────────────────────►│
        │  ◄─── { protocolVersion, capabilities, ... }    │
        │                                                  │
        │  3. POST notifications/initialized              │
        │ ───────────────────────────────────────────────►│
        │  ◄─── 204 No Content                            │
        │                                                  │
        │  4. POST tools/list                             │
        │ ───────────────────────────────────────────────►│
        │  ◄─── { tools: [9 tool defs] }                  │
        │                                                  │
        │  El usuario habla con Claude — Claude decide    │
        │  cuándo usar las tools de Brote.                 │
        │                                                  │
        │  5. POST tools/call (ej: list_conversations)    │
        │ ───────────────────────────────────────────────►│
        │  ◄─── { content: [{ type: "text", text }] }     │
```

Claude lee el `content.text` (JSON stringificado en nuestro caso) y lo
incorpora al razonamiento para responderte.

## Troubleshooting

### Claude Desktop dice "Server disconnected"

1. Abrí los logs: `~/Library/Logs/Claude/mcp-server-brote.log` (macOS).
2. Buscá la última línea con `error` o `Connection error`.
3. Causas comunes:

| Error en log | Causa | Fix |
|---|---|---|
| `EACCES` o `npx: command not found` | Node/npm no están en el PATH del proceso Claude | Asegurate que Node está instalado globalmente (`brew install node`) y reiniciá Claude |
| `401 unauthorized` | API key inválida o revocada | Generá una nueva en Settings → Integraciones → Desarrollador → API key |
| `400 Invalid JSON-RPC 2.0 envelope` | Tu instalación de mcp-remote usa una versión vieja del protocolo | `rm -rf ~/.npm/_npx && killall node` para que descargue la última |
| `EAI_AGAIN` o timeout | DNS o red bloquea brote.ai | Probá `curl https://brote.ai/api/mcp` desde la terminal — si no responde, problema de red |

### Las tools no aparecen aunque conectó

Asegurate que Claude Desktop esté en una **conversación nueva** (no en
una existente abierta antes del restart). Los MCP servers solo se cargan
al abrir conversación.

Probá pedirle explícitamente: *"qué tools del MCP brote tienes
disponibles?"*. Debería listar las 9.

### Claude usa Supabase u otro MCP en vez de Brote

Cuando tienes varios MCP servers configurados, Claude elige cuál usar.
Si Brote no aparece como opción válida para una intención, generalmente
es porque:
- La tool tiene una descripción ambigua → reportanos y la mejoramos.
- Le pediste algo demasiado genérico ("traeme mis datos") sin mencionar
  Brote. Sé explícito: *"de Brote, listame..."*.

### Quiero ver las requests en tiempo real

```bash
tail -f ~/Library/Logs/Claude/mcp-server-brote.log
```

Cada `Message from client` muestra el JSON-RPC entrante. Cada
`Connection error` el saliente con código.

## Conectar desde un agente propio (HTTP raw)

Cualquier agente que hable JSON-RPC 2.0 puede usar Brote.

### 1. Initialize

```bash
curl -X POST https://brote.ai/api/mcp \
  -H "Authorization: Bearer brote_live_TU_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "initialize",
    "params": {}
  }'
```

Devuelve `protocolVersion`, `serverInfo` y `capabilities.tools`.

### 2. Listar tools

```bash
curl -X POST https://brote.ai/api/mcp \
  -H "Authorization: Bearer brote_live_TU_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": 2,
    "method": "tools/list"
  }'
```

Devuelve array con definiciones JSON Schema de cada tool.

### 3. Llamar a una tool

```bash
curl -X POST https://brote.ai/api/mcp \
  -H "Authorization: Bearer brote_live_TU_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": 3,
    "method": "tools/call",
    "params": {
      "name": "list_conversations",
      "arguments": { "status": "open", "limit": 5 }
    }
  }'
```

El `result.content[0].text` trae el JSON con la respuesta.

## Permisos y scopes

Por ahora las API keys de Brote tienen scope `*` — pueden invocar
cualquier tool sobre cualquier dato de la org. Próximamente vamos a
agregar scopes granulares (`conversations:read`, `contacts:write`, etc).

<Aside type="caution">
Tratá tu API key como contraseña — el agente que la tenga puede leer
todo tu inbox, mandar mensajes a tus clientes, modificar contactos y
generar cobros. Si se filtra, rotala desde Settings → Integraciones →
"Revocar".
</Aside>

## Discovery

Si necesitás verificar que el endpoint es realmente MCP sin enviar
credenciales, hacé un `GET`:

```bash
curl https://brote.ai/api/mcp
```

Devuelve metadata pública: nombre del servidor, versión, protocol_version,
transport, métodos soportados, link a esta doc.

nativo. Tu agente IA externo puede cobrar y despachar en CL sin que tú
escribas integraciones.
