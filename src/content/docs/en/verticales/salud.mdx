In healthcare, the operational bottleneck is **scheduling**. Clinics lose hours on confirmations, rescheduling, reminders. Brote automates 70-80% of it without replacing the actual clinical role.

<Aside type="caution" title="Brote is NOT medical advice">
The AI agent **does NOT diagnose or recommend treatments**. It's configured for operational triage (which specialty, how long the appointment is, which documents to bring) and refers to a professional when needed. Any real clinical question → handoff to a human.
</Aside>

## The typical flow

1. **Patient writes** ("I need to book with Dr. Pérez").
2. **Agent checks availability** in the doctor's [Google Calendar](/en/integraciones/calendar/).
3. **Proposes slots** + books the one they pick.
4. **Captures patient details** (name, RUT, isapre/fonasa, reason for the visit).
5. **Confirmation** + invite on the patient's calendar.
6. **Automatic reminders**: 24h before + 1h before.
7. **Easy rescheduling**: if the patient says they can't make it, the agent proposes slots again.

## Recommended setup

### Custom fields

```
rut_paciente (text)
isapre_fonasa (select)
fecha_cita (date)
duracion_cita (number, min)
medico_preferido (text)
motivo_consulta (text — alto nivel, no detalles clínicos)
primera_consulta (boolean)
acompanante (boolean)
```

### Useful tags

`cita_confirmada`, `primera_vez`, `reagendo`, `no_show_previo`, `fonasa`, `requiere_examenes_previos`

### Key integrations

- **[Google Calendar](/en/integraciones/calendar/)**: a separate calendar per doctor/professional, the agent reads real availability.
- **[Webhooks](/en/integraciones/webhooks-api/)**: if your clinic uses clinical software (Doctoralia, Reservo, Calmedical), a webhook syncs the appointment.
- **[Mercado Pago](/en/pagos/mercado-pago/)**: collect the out-of-pocket copay before the appointment.

## No-shows: the real problem

Clinics lose 15-25% to no-shows. Brote helps bring that down:

- **24h reminder** → confirms or reschedules automatically.
- **1h reminder** → last chance.
- **If a patient tagged `no_show_previo` books again**: the agent asks for an **advance copay via MP** as a commitment.

With these 3 → no-shows drop to 5-10%.
